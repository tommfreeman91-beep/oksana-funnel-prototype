# Прототип экранов — воронка с уроком (Оксана)

Статический фронтенд-прототип (HTML/CSS/JS, без бэкенда) — 11 слайдов,
листаются кнопкой «Далее» как сторис/онбординг. Бота и приём заявок
подключаем следующим шагом.

## Как посмотреть

```bash
cd app
python3 -m http.server 8934
# затем открыть http://localhost:8934 в браузере
```

Или просто открыть `index.html` двойным кликом (фонты и Telegram WebApp
SDK подтянутся из интернета, остальное работает офлайн).

На широком экране показывается декоративная рамка телефона (для
удобства ревью), на узком/мобильном — интерфейс на весь экран, как
внутри настоящего Telegram Mini App.

## Порядок слайдов

1. Хук / обещание (фото `IMG_4450.PNG`)
2. История — трудности (фото `IMG_4448.PNG`)
3. История — перелом (без фото, цитата)
4. Переход к уроку
5. Урок / видео (постер `IMG_4449.PNG`) + 8 блоков метода + результаты
6–8. Квиз (3 вопроса)
9. Заявка
10. Подтверждение + бонус
11. Библиотека материалов

## Видео урока

Хостится своим сервером на Railway (не YouTube/VK) — файл лежит на
Railway Volume, примонтированном к `oksana-funnel-backend`, отдаётся
через `StaticFiles` по `/videos/lesson.mp4`. Слайд 4 — нативный
`<video>` с `controls`; перемотка вперёд дальше уже просмотренного
места запрещена в JS (`app.js`, обработчики `timeupdate`/`seeking` на
`#lessonVideo`) — назад и пауза свободны. Подробности заливки/замены
файла — в `backend/DEPLOY.md`.

## Бонусы

Три реальных файла лежат в `assets/bonuses/` и открываются по клику в
новой вкладке на слайдах 9 (заявка принята) и 10 (библиотека
материалов):

- Гайд: как оценить уровень ученика за 30 минут (PDF)
- Шаблон ответного сообщения ученику (PNG)
- Экспресс-способы привлечения учеников 2026 (PDF)

## Дизайн

Палитра и типографика — по фотосессии из `материалы/фото`: тёплый
кремовый фон, бордовый акцент, камель, графитовый текст, Playfair
Display + Inter. Токены — в начале `styles.css` (`:root`).
